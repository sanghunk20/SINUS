# --- Qwen3.5 gated-delta-net: torch fallback (NO Triton) ---
# fla / liger / causal-conv1d are Triton JIT kernels and need a C compiler at run time. On a
# machine without one, generate() fails with "Failed to find C compiler".
# -> Leaving all three uninstalled makes transformers take the pure torch path
#    (GDN=torch_chunk_gated_delta_rule, RMSNormGated=Qwen3_5RMSNormGated, standard CE).
#    Generation speed and output are unchanged (verified: 71s, identical report).
#    liger is used during training only, to avoid the large-vocabulary cross-entropy OOM;
#    install liger_kernel if you train and hit that. Where the fast kernels do work, set
#    TF4_TORCH_GDN_FALLBACK=conv to keep only the causal-conv1d kernel on the reference path
#    (it segfaults on some stacks; the loss differs by less than 1e-3 relative).
